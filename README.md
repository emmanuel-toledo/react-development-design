# react-development-design

Skill para agentes de IA con el objetivo de estandarizar la estructura de un proyecto desarrollado con React.

## Skills disponibles

- `react-feature` — anatomía de una feature (`src/features/<feature>/`).
- `react-architecture` — capas, imports, public API, feature graph.
- `react-shared` — carpeta `src/shared` y promoción.
- `react-stack` — stack de librerías y versiones.
- `react-testing` — estrategia, estructura y cobertura de tests.
- `react-effects` — política de efectos (useEffect, etc.).
- `react-forms` — formularios con RHF + Zod.
- `react-routing` — rutas, params, guards, layouts.
- `react-data` — capa de datos, clientes, React Query, mocks.
- `react-a11y` — accesibilidad: semántica, foco, teclado, contraste, skip links.
- `react-performance` — rendimiento: splitting, memoización, virtualización, profiling.
- `react-conventions` — convenciones: commits, PRs, branching, code review.
